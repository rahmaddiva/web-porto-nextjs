# Web Portfolio Next.js

Modern, animated, and responsive portfolio website built with Next.js, React, and Tailwind CSS. Features attractive typography, black & white theme, animated backgrounds, and a dynamic sticky navbar.

## ✨ Features

- Animated headline and section transitions
- Staggered sticky navbar with GSAP animation
- Threads (OGL) animated background on Home section
- Responsive layout for desktop and mobile
- About section with skill icons
- Project section with CardSwap carousel
- Contact section with social media links
- Attractive black/white/gray theme with accent color

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/rahmaddiva/web-porto-nextjs.git
cd web-porto-nextjs
```

Install dependencies:

```bash
npm install
# or
yarn install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Technologies Used

- Next.js (App Router)
- React
- Tailwind CSS
- GSAP (animations)
- OGL (Threads background)
- react-icons

## 📁 Project Structure

- `app/page.tsx` — Main page and sections
- `app/component/` — Custom React components
- `public/assets/` — Images and static assets
